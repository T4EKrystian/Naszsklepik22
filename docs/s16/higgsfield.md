# Szkic 16: seria Higgsfield

Model `gpt_image_2_5`, jakość medium, 2k (1 kredyt za obraz). Styl wspólny (C-62): sumi-e, granatowy tusz rozcieńczony do szaroniebieskich laserunków, ciepły papier washi, mokry pędzel, temat wchodzi zza lewej krawędzi, prawa część pusta, bez tekstu, pieczęci i ramek.

**Status pobrania:** wszystkie obrazy są gotowe w bibliotece Higgsfield. Ta sesja nie może ich pobrać: host `d8j0ntlcm91z4.cloudfront.net` jest zablokowany w jej kontenerze (zmiana ustawień sieci działa dla nowych kontenerów). W nowej sesji: `curl -fsS -o art/higgsfield/<klucz>.png <url>` dla każdego wiersza, potem `tools/split.py` i podpięcie w `ART`. Do tego czasu strona używa zapasów proceduralnych.
